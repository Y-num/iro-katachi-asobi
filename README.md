# いろと かたち あそび（3歳からの知育マッチングゲーム）

3歳前後のお子さまが楽しく「色」と「形」を学べる、シンプルなWeb知育アプリです。  
インストール不要で、スマホ・タブレット・PCのブラウザからすぐに遊べます。

## 特長

- **3つのあそびモード**
  - **いろあわせ**: 「あか」「あお」「きいろ」「みどり」「おれんじ」「むらさき」の6色から同じ色を探します。
  - **かたちあわせ**: 「まる」「さんかく」「しかく」「ほし」「はーと」「だいや」の6種類から同じ形を探します。
  - **いろと かたち**: 「あかい ほし」など、色と形の組み合わせを見つけるステップアップモードです。
- **タップでもドラッグ＆ドロップでも遊べる**
  - まだドラッグ操作が難しいお子さまでも、カードをタップするだけで遊べます。
  - 上のお題枠にカードをドラッグしてはめ込む遊び方もできます。
- **やさしい音声・効果音（ON/OFF切り替え可能）**
  - Web Speech API によるひらがなのお題読み上げと、Web Audio API による優しい効果音付きです。
  - 間違えても不快なブザーは鳴らず、「こっちかな？」と優しく促します。
- **ごほうびタイム**
  - 5問クリアすると紙吹雪とキラキラメダルでお祝いします。

## 遊び方（ローカルで開く場合）

`index.html` をブラウザでそのまま開くだけで動作します（ビルド手順やサーバーは不要です）。

## 技術構成

- HTML5 / CSS3 / Vanilla JavaScript
- 外部アセット・依存ライブラリなし（SVG / Canvas / Web Audio API / Web Speech API）
